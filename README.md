# ♟️ Chess Academy - Learn and Master Chess

## 🧠 Deskripsi Proyek

**Chess Academy** adalah landing page interaktif untuk platform belajar catur yang membantu pengguna memulai perjalanan menjadi Grandmaster.  
Website ini dirancang dengan **HTML5**, **CSS3**, dan **Bootstrap** agar tampil modern, responsif, dan user-friendly di berbagai perangkat.

---

## ✨ Fitur Utama

- 🎯 **Hero Section Interaktif:** menampilkan slogan _“Your Path to Becoming a Chess Grandmaster Starts Here”_ dengan background papan catur.
- 🔘 **Tombol Sign-In:** tombol autentikasi menggunakan gaya modern (Apple dan Google style).
- 📱 **Desain Responsif:** menggunakan grid system dari Bootstrap agar tampilan tetap optimal di semua ukuran layar.
- 🎨 **Tampilan Elegan:** menggunakan kombinasi warna gelap dan kontras teks putih untuk efek profesional dan fokus pada konten utama.

---

## 🧰 Teknologi yang Digunakan

| **HTML5** | Struktur page dan elemen konten. |
| **CSS3** | Styling, color, dan efek visual. |
| **Bootstrap 5** | Framework front-end untuk responsivitas dan komponen siap pakai. |
